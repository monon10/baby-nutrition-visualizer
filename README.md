# baby-nutrition-visualizer

授乳（粉ミルク・母乳・混合）と離乳食から得られる栄養素を、日本人の食事摂取基準（2025年版）と比較して可視化するブラウザ内シミュレーターです。

## 公開版

GitHub Pages では、最新版の `milk_nutrition_visualizer.html` を **`index.html` に改名してリポジトリの `main` ブランチ直下**に配置してください。

想定URL:

`https://monon10.github.io/baby-nutrition-visualizer/`

## 最新版に含まれるもの

- 対象月齢: 5〜18か月
- 粉ミルク / 母乳 / 混合授乳
- 粉ミルク主要13製品
- 母乳（成熟乳）の標準成分推定
- 母乳と粉ミルクの割合指定
- 母乳量不明の混合入力
- 手作り離乳食 21品
- 市販ベビーフード 38品
  - 和光堂 18品
  - ピジョン 20品
- 市販品の範囲表示は min/max のまま保持
- 非公開・未取得の栄養素は 0 とみなさない
- 日本人の食事摂取基準（2025年版）との比較
- URLパラメータによる条件共有

## データ上の重要な注意

このツールは栄養摂取量の概算・可視化を目的としたもので、診断や個別の栄養指導を目的としません。

「基準比100%未満」は欠乏を意味しません。目安量（AI）、推奨量（RDA）、推定エネルギー必要量（EER）などはそれぞれ意味が異なります。

母乳成分は標準成分による推定であり、実際の母乳成分には個人差・時期差があります。

市販ベビーフードについて、メーカー等が公開していない栄養素は `0` ではなく「不明・非公開」として扱います。

## 食材コレクション

左の入力欄下部に100食材の食経験記録を追加しました。検索・カテゴリ・記録済み/未記録で絞り込めます。チェックはこの端末のブラウザに保存し、共有URLには含めません。ブラウザの保存データを削除すると記録も消えます。

添付の `food_master_100_patch.js` v2 を内蔵しています。`nutritionReady:true` かつ既存の栄養DBに接続できる21品のみ、今日の離乳食へ追加できます。`nutritionReady:false` の79品は食経験の記録専用で、栄養計算に含めません。100品の達成を促す機能ではありません。
